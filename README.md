### What I work on
 
**Type-safe architecture** — I designed and built our organization-wide API contract layer on oRPC and Zod, spanning 58 domains and ~330 procedures consumed by 8 applications across web, mobile, CLI, and backend, with automated schema generation keeping contracts in sync with the database.
 
**Payments** — Debit card platform end to end: full lifecycle state machine for activation, suspension, reordering, and closure, plus in-app wallet provisioning for iOS and Android through a custom Expo native module. Also Stripe subscriptions and donations, and a points-based rewards economy.
 
**Cross-platform delivery** — React and Next.js on the web, React Native and Expo on mobile, Node.js on the backend. Led a full Gatsby to Next.js migration for first-class SSR and per-route rendering control.
 
**Quality and security** — Monorepo testing with Vitest, Jest, and Playwright. I care about secure coding practices and won a cybersecurity hackathon at CyHub in 2025.
 
**AI-assisted engineering** — I built a structured LLM knowledge base documenting our architecture and domain logic, and authored the rules that drive AI-assisted code review, test generation, and documentation across the team's daily workflow.
